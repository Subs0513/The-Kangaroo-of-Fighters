# The-Kangaroo-of-Fighters

## Introduction

The Kangaroo of Fighters is a fun 2D fighting video game written by python. In this game, there are two kangaroos battling with each other, and it won’t stop until the health bar of one player’s kangaroo runs out. This game combines fast action, simple controls, and cartoon-style graphics to create an exciting playing experience. Players can jump, punch, and kick to control the kangaroo to win the match. It’s designed for people who enjoy casual fighting games and want something more playful and easy to learn. It is suitable for students, game lovers, and anyone who loves Australian wildlife.
